# 工业化导演方法（分镜增强）

> 本文给 `storyboard_breaker` 提供参考项目的工业化细化，作为分镜拆解时的方法论依据：
> **分镜五要素 / 12 节拍情绪曲线 / 2×2 顶视图机位 / 武戏与玄幻专项 / H3 时长预算 / 声音三层电平**。
> 与「全片宪法」（`剧本/00_项目配置/全局硬约束（全片宪法）.md`）配套使用；宪法为硬约束，本文为方法。

---

## 1. 分镜五要素（镜头描述必含，缺一不可）

除 `title / action / dialogue` 外，每个镜头的 `image_prompt` / `video_prompt` 都要显式落实五要素，
避免写「主角在客栈」这种只有"谁在哪"的泛泛描述：

1. **主体及环境**：谁在画面里 + 所处环境 + 与背景的空间关系（前后 / 远近）。
2. **构图与空间**：人物在画幅中的位置、前景/中景/背景关系、纵深。
3. **光影与色调**：主光源方向、色温（冷 / 暖）、明暗对比 —— 决定氛围。
4. **摄影与成像**：景别、景深、焦距、曝光（特写浅景深、全景深景深）。
5. **机位与角度**：平 / 俯 / 仰 / 侧 / 背 + 顶视图机位编码（见下）。

> prompt 示例：`close-up, eye-level, warm key light from left, frosty dawn harbor,
> a 15-year-old fisherman boy ... , shallow depth of field, 3/4 front angle`

## 2. 2×2 顶视图机位（CAM1~4 + 180° 轴线）

用「顶视图俯拍」来定机位：把场景画成俯视平面，标出 A、B 两人站立点。

- **轴线原则**：两人对视的连线 = 轴线；机位只能在轴线**同一侧**（180° 内），跨轴线 = **跳轴**（观众方向感错乱）。
- 四个标准机位（以 A、B 对坐为例）：

| 机位 | 类型 | 画面 | 用途 |
|---|---|---|---|
| CAM1 | 外反打（过肩） | 拍 A，B 背影在前景 | A 为主 |
| CAM2 | 外反打（过肩） | 拍 B，A 背影在前景 | B 为主 |
| CAM3 | 内反打（单人特写） | 只拍 A 正面近景 | 聚焦 A 表情 |
| CAM4 | 内反打（单人特写） | 只拍 B 正面近景 | 聚焦 B 表情 |

- **双人对白标准正反打** = `CAM3 → CAM4` 交替（单人特写），或 `CAM1 → CAM2`（过肩），**全程不跳轴**。
- 在分镜 `angle` 字段可直接写机位编码，如 `angle: 外反打-过肩(CAM1)`，保证正反打轴一致。

## 3. 12 节拍情绪张力曲线（整集节奏标尺）

把一集剧本按叙事节拍切成 12 拍，每拍标**情绪张力 1~10**，形成曲线：

```
起(引子) → 承(铺垫) → 转(冲突) → 高潮 → 合(收束)
张力:  4      5→6     6→8      9→10    5→6→hook
```

- **节奏原则**：开头 hook 上浮；中段起伏交替；每 2~3 拍一个情绪小峰；结尾 hook 再上浮一次（留钩子）。
- **分镜时长据此来定**：情绪峰值镜用**短切 3~5s** 提节奏；情绪谷值 / 空镜用**长镜 8~15s** 留白呼吸。
- **全篇时长档位应 ≥3 种**（QC `P1-TEMPO-FLAT` 会拦截时长雷同 / 无节奏的整集）。

> 用途：`storyboard-breaking` 之前先在剧本层画一张 12 节拍曲线，再据此切分镜时长，
> 保证"该紧张的紧张、该留白的留白"，而不是每镜都 10s 匀速。

## 4. 武戏 / 玄幻专项分镜

### 4.1 武戏（动作戏）
- 单场武戏**控制在 15s 内交付一个完整攻防回合**，完播率优先，不硬拖时长。
- 拆成 **R1 起手 → R2 交击 → R3 收势** 三个小段，每段 3~5s，接招拆招清晰。
- 每一镜必须写出：**谁 + 兵器/部位 + 发力方向 + 命中结果**，避免只写「打斗」。
- 兵器动作写具体：刀剑**出鞘 / 收鞘 / 劈砍 / 格挡 / 刺击**；多人混战拆成「主角对 A / 主角对 B」逐组处理。

### 4.2 玄幻 / 法术（R3）
- 分解五要素：**施法者（谁）+ 法诀/法器（什么）+ 能量具象（形与色）+ 攻防目标（对谁）+ 结果（命中/化解/清场）**。
- 能量具象要具体：`青色剑气成弧`、`赤色火莲自地面绽放`，**不写**「施放法术」。
- 对军清场：明确「范围内若干杂兵被掀飞」，给出画面结果；避免法器凭空消失。
- **五行对应画面特征**：金（锋利 / 金芒）、木（藤蔓 / 缠绕）、水（漩涡 / 冻结）、火（烈焰 / 爆燃）、土（岩刺 / 塌陷）。

## 5. H3 三层解耦 + 时长预算协议

- **三层解耦**：`image_prompt`（首帧 / 参考画面）与 `video_prompt`（时间推进 / 动作变化）
  与 **audio**（对白 / BGM / 音效）三套分开写，互不混写、互不替代。
- **时长预算**：整集 180s ≈ 14~15 组；**每组 ≤15s**；组内以 **3s** 为最小推进单元连续分段。
- **对白镜 5~8s**（1~2 句）；**动作 / 空镜 10~15s**；超过预算必须拆组 / 切镜，不硬塞。

---

## 6. 声音三层相对电平（主次分明）

- **相对电平：对白 0dB > 音效 −6dB > BGM −14dB**。
- 整集 **loudnorm 目标 −14 LUFS** 统一（`scripts/assemble_episode.py --loudnorm`）。
- **H3 原生音频为主**：对白 + 环境声靠分镜的音频 / Speaker / Voice / Emotion 控制。
- BGM / 音效缺的口子用剪映音乐库 / 音效库补；对白不稳才用 MiniMax `voice_clone`。
- 分镜 `bgm_prompt` 只描述 BGM **意图**（风格 + 速度 + 情绪），`sound_effect` 只描述关键动作 / 环境音，
  二者只写「要什么」，不写「要不要」、不写「BGM 大 / 小」（那交给电平协议）。
