# 角色与场景提取指南

## 角色提取规范

### 角色识别（谁在说话）

- 剧本对白行格式为「角色名：（状态/表情）台词」，**冒号前的名字就是说话角色**，这是角色名单的首要来源。
- 必须提取每一个「角色名：」前缀出现过的角色，**绝不遗漏任何有台词的角色**。
- 同一角色若有别名/简称/昵称，要归一到同一角色全名（如「何长青」与「长青」是同一人）。
- 旁白、画外音单独记为「旁白」角色，不要与其他角色混淆。

提取的角色信息包含：
- **姓名**：角色全名
- **角色定位**：主角/配角/龙套
- **外貌描写**：性别、年龄、体型、面部特征、发型、着装（300-500字）
- **随身道具**：该角色随身携带/手持、能明确归到其名下的道具；没有则为空数组
- **性格特点**：核心性格标签
- **角色描述**：背景故事和关系

### 外貌提取颜值规则（重要）
- **默认角色要耐看**：除小说明确写角色丑/毁容/脸部疤/黄牙/烂牙/麻子等之外，外貌描写中默认体现五官端正、清秀耐看（如"眉目清秀""五官端正""干净利落"），**不要**把"普通""清瘦""憔悴""饱经风霜"等非丑设定写成难看。
- **凶悍/阴鸷/狰狞表情不等于丑**：写"面露凶相""凶悍""阴狠""狞笑"等气质的角色（如反派、打手），外貌仍要五官端正，只保留凶悍表情/气质词，不生成歪脸。
- **丑要写进剧本才丑**：只有小说原文明确用"丑陋/毁容/疤脸/黄牙/烂牙/麻子"等描述的角色，才按原文如实提取，且要在 `appearance` 中保留该丑的特征词（供后续生成时豁免颜值修饰）。仅写"狰狞表情"不构成丑。
- **外貌描写要具体到可生成（含下装，必写）**：体型（清瘦/壮实/高挑）、肤色（晒黑/苍白）、五官（眼睛、眉毛、脸型）、发型（长短/发饰/发型状态）、服装（材质/颜色/款式/配饰）都要写出，供三视图/角色图直接复用，避免凭想象生成换装换脸。
- **下装必写（硬约束，缺一不可）**：服装必须写全「上装 + 下装 + 鞋」三段，尤其**下装/裤装不允许省略**。古装长衫/长袍/裙装（盖腿款式）必须写明**内着长裤、足穿布靴/鞋**——例如「一袭素白古装长衫，内着素白长裤，足蹬布靴，从头到脚衣着严整」。**禁止只写单件袍/裙**（如只写「长衫/长裙/连衣裙」），否则三视图会生成「袍下光腿 / 没裤子 / 短装露腿」。男女通用：男=长裤+鞋；女=长裤（或裙装）+**内衬长裤**+鞋。`role_look()` 会兜底补「内着长裤」，但提取层必须先写完整、不依赖兜底。
- **外貌段与角色库 image_prompt 的衔接**：保存角色后其 `image_prompt` 按《grid_prompt_generator》规范生成——统一风格约束段（写实CG融合+真实皮肤纹理）与颜值修饰词**前置内嵌在 image_prompt 开头**（丑角色豁免颜值词），本步骤提取出的外貌描写作为该角色**独有的中段**放入，不要重复写风格词/贴通用模板。

### 随身道具归属规则（谁有谁没有）

- 只认**剧本原文写出来由该角色随身带/手持**的物：如「钱彪腰间别短刀」→短刀归钱彪；「帮众提着铁皮灯笼」→铁皮灯笼归帮众/打手；没有原文背书的不得按职业/身份脑补补道具（渔民不等于随身带鱼网，帮派不等于人人佩刀）。
- 剧本从未写该角色随身带任何物 → **无随身道具**。
- 多人共持同一件共用物可多人各持（铁皮灯笼 = 金河帮标志道具，钱彪与打手甲都写 `铁皮灯笼`）。
- 入库时写入角色 `随身道具` 字段（数组，元素为道具中文名；空数组 = 无）；该字段同步驱动三视图道具板（见方案第十三章），确保"谁有道具、谁没有道具"一眼分明。
- 有随身道具的角色，其道具描述也要出现在 `appearance` / `image_prompt` 中，保持角色卡与道具板一致。

## 场景提取规范

提取的场景/背景信息包含：
- **地点**：具体场所名称
- **时间**：时间段和光线条件
- **氛围**：环境氛围描述
- **提示词**：用于AI图片生成的英文提示词（纯背景，不含人物）

## 道具提取规范

提取的道具信息包含：
- **名称**：道具名
- **类型**：日常/武器/交通/装饰等
- **描述**：外观和用途
- **图片提示词**：用于AI图片生成的英文提示词

## 使用步骤

1. 调用 `read_script_for_extraction` 读取当前集剧本
2. 调用 `read_existing_characters` 查看项目已有角色和当前集已关联角色
3. 调用 `read_existing_scenes` 查看项目已有场景和当前集已关联场景
4. 只提取当前集真实涉及的角色和场景
5. 调用 `save_dedup_characters` 保存角色并自动关联到当前集
6. 调用 `save_dedup_scenes` 保存场景并自动关联到当前集

## 提取后审核门禁（渐进而多次，必跑）

保存角色后必须渐进多次审核角色卡，未通过与"时代 / 剧本 / 小说"不符的角色卡要回归重写，**不得带病进入三视图生成**。运行：

```
python scripts/qc_characters.py --skip-3view    # 提取后（三视图尚未生成，跳过 R4）
# 生成三视图/首帧后（见 build_new_workflows）再跑全量：
python scripts/qc_characters.py
```

逐轮把关（`scripts/qc_characters.py` 引擎，P0 默认阻断、P1 提示）：
- **R2 时代合规**：`era` 必须写 ancient / modern，且 `image_prompt` / `appearance` 的着装强词与时代一致。古代角色出现「西装 / 职业装 / 现代长裤」等现代强词、或现代角色出现「广袖 / 长袍 / 汉服 / 古装」等古装强词，都属"不符时代"，必须改。
- **R3 剧本 / 小说一致**：角色 `image_prompt` 必须写全「上装 + 下装（长裤）+ 鞋」，避免三视图露腿缺裤；道具只能进道具板，角色卡禁止出现「手持 / 提着 / 握着」等人物手持词；不得套用泛指模板。分镜引用的角色必须都已提取。
- **R5 资产分级**：补 `asset_level`（A/B/C）以确定复用优先级。

## 当前集规则

- 目标是补齐“当前集”需要的角色和场景，不是重扫整个项目
- 若角色或场景已在项目中存在但当前集未关联，仍应复用并关联到当前集
- 若项目中已有同名角色或同地点同时间场景，优先复用，不要重复创建

## 资产台账分级与亲缘遗传（全片复用）

### 资产分级（一次性资产，写入 `asset_level` 字段）
- 角色 / 场景 / 道具是**一次性资产**，第一集锁定后全集复用，不重复创建。
  - **A 级**：主角 / 核心 CG 角色 —— 锁定 face / voice / 外观，跨集不变。
  - **B 级**：配角 / 复用道具（帮众、铁皮灯笼等）—— 少量跨集复用。
  - **C 级**：龙套 / 环境 / 日抛道具 —— 用完即弃，不入长库。

### 亲缘 / 多梯队遗传推导（跨集新角色）
- 新角色若与已有 A/B 级角色有亲缘（父子 / 母女 / 兄弟 / 师徒），外貌从亲代**遗传 40%~60% 骨相关联**：
  `骨相（脸型 / 眉眼 / 鼻梁）+ 发色 + 瞳色 + 体型倾向` 从亲代继承；气质 / 服装按新角色设定差异化。
- 例：父亲国字脸浓眉，其子继承国字脸 + 相似眉眼（骨相关联），但神情 / 服装 / 年龄区别开。
- 写外貌时标注 `遗传自 cXX / 有别于 cXX`，保证家族相似但不撞脸。

### 别名归一（跨集同一人）
- 同名角色别名 / 简称 / 昵称 / 称号（如「何长青」「长青」「何帮主」）归一到同一全名，只建一条记录。
- 跨集再出场沿用同一 id + 同一 speaker_id + 同一外观，不另建角色。
