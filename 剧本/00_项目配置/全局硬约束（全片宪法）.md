# 全局硬约束 · 全片宪法（H3 固定方案）

> 本文是整部短剧生产的**宪法**：任何角色 / 场景 / 分镜 / 提示词在生成时，
> 只要与本文冲突，一律以本文为准（用户在本集**显式指令**除外 —— 用户指令 > 本文默认值）。
>
> 字段口径与《小说转短剧视频生产方案（H3固定方案）》、`scripts/` 各脚本保持一致。
> 开工前先通读《方案》，再对照本文；生成时逐条自检。

---

## 0. 总纲：先定"宪法"再开工

- 开工前先锁定 6 件事：**画幅 / 美学与模型 / H3 时长预算 / 对白规格 / 一致性锚点 / 声音电平**。
- 进阶还要定：**世界观时代锚点 / 图像资产体系（三视图·九宫格·首尾帧）/ 角色外观硬约束 / 提示词分层 / 音色锚 / 数据契约 / 质量门禁**，见下文 11~19 节。
- 本文以下为默认值；用户指令 > 本文；本文 > 《方案》文档（矛盾时改方案文档）。

## 1. 画幅铁律（用户指令优先）

- **默认 横屏 16:9**：H3 生成 **1280×736**，剪映导出 **1920×1080**（见《方案》十六「成片规格」）。
- 若本剧走**竖屏 9:16**（`scripts/build_new_workflows.py` 当前实现：生成 **736×1280** / 导出 **1080×1920**），
  **全片统一到底**，绝不混用横竖；竖屏素材只能左右黑边裁切，损失画质。
- 用户在本集显式指定其他画幅时，以用户为准，且同一集内沿用；**首帧 / 尾帧文生图、分镜、剪辑调色全程同一比例**。

> ⚠️ 当前仓库存在 横屏 16:9（方案文档）与 竖屏 9:16（build 脚本 docstring）两套口径，
> **以实际使用的工作流 / 用户指令为准**；确定后把另一套口径同步改正，避免混用。

## 2. 美学与模型（唯一风格，不强词重复）

### 2.1 模型与参数（固定一套）

- **生图模型四件套 + 角色 LoRA**：`qwen_image_2512_bf16` + `qwen_2.5_vl_7b_fp8_scaled` +
  `qwen_image`（clip）+ `qwen_image_vae` + **「国漫短剧3D CG质感角色」LoRA**。
- **生图分辨率**：横屏 **1216×832**（Qwen 常用横屏）；竖屏 **736×1280**。
- **采样参数（固定）**：`steps=30`、`cfg=4.0`、`seed=42`、`sampler=euler`、`scheduler=normal`；
  `denoise`：**首帧 text2img = 1.0**，**尾帧 img2img ≈ 0.55**（见 11.3）。
- **角色 LoRA 强度 0.8**；**场景 / 空镜不用角色 LoRA**（纯环境挂角色 LoRA 会强塞人物）。
- **视频**：H3 fl2v **turbo LoRA 8 步**（`minimax_h3_fl2v_turbo_8step_v1.0_comfyui_bf16`），**24fps**；导出 1920×1080。

### 2.2 风格唯一，且前置内嵌、下游幂等

- **风格唯一** = 写实 CG 与动漫融合的 3D 国漫动画电影质感（`STYLE_FUSION`）。
  - 角色统一约束段**前置内嵌**到 `剧本/03_角色场景/角色.json` 每个角色的 `image_prompt` 开头：
    `stylized 3D Chinese anime character, ... , Chinese Guoman 3D style, East Asian anime face`。
  - 下游引用 `image_prompt`（三视图 / 分镜首尾帧）时**不再重复拼风格词**（幂等）；
    旧角色库缺约束段时由构建脚本 `STYLE_FUSION` / `_fusion_base()` 兜底补齐（检测标记 `stylized 3D Chinese anime character`）。

### 2.3 三向抑制负面 + 哑光布料（防三个极端）

- 统一底座 `NEG_CHAR_FUSION`：**双向抑制塑料CG / 纯2D动漫 / 真人实拍**。
  - **严禁**把「真人皮肤纹理 / 毛孔」当负面词（否则得到光滑无纹的塑料娃娃脸）；防的是"真实照片 / 电影剧照"整体风格。
- **服装布料**：统一哑光（`FABRIC_MATTE`），进正面 + 负面（`塑料衣服/光滑塑料布面/无布料织纹/反光布面/缎面强反光`）。
- 负面词**三套**，按素材类型选用：

| 素材 | 风格词（正向） | 负面词 |
|---|---|---|
| 角色三视图 | `STYLE_FUSION` + `FABRIC_MATTE` + `LOWER_BODY_PANTS` | `NEG_GRID_FUSION` |
| 场景九宫格（纯环境） | `STYLE_SCENE`（无皮肤/面部/五官词） | `NEG_SCENE_GRID`（强排人） |
| 分镜首帧/尾帧（有人） | `STYLE_FUSION` + `ERA` | `shot_negative()`（按在场人数） |
| 分镜空镜（无人） | `STYLE_SCENE` + `ERA` | `NEG_SCENE_GRID` |

> `STYLE_SCENE` = 纯环境专属（`3D次时代CG风格渲染, PBR材质, ... Chinese digital environment concept art`），
> **不含任何皮肤/面部/五官词**；`NEG_SCENE_GRID` = 强排人（`人物，人脸，人像，人影，全身人，半身人，背影，身体，手臂，手指，五官...`）
> + 格子约束（`格子重叠/合并/缺失/溢出`）。防止模型把场景画成"人物三视图"。

## 3. H3 时长预算协议

- **单镜时长上限 15s**（QC `P0-DUR15` 阻断项）。
- 整集 **180s ≈ 14~15 组**；**每组 ≤15s**，组内以 **3s** 为最小推进单元连续分段。
- **对白镜 5~8s**（只装 1~2 句台词）；**动作 / 空镜 10~15s**。
- **台词时速**：极速 5 字/s（QC `P0-DIALOG-OVERRUN` 用最快有效口播判定）；停顿预算：顿号 0.1~0.3s、句末 0.3~0.6s。

---

## 4. 对白规格

- **一镜一人说（ONE_SHOT_ONE_SPEAKER）** —— 最高优先级铁律。
- **双人对白拆正反打**：A 说一句一个镜，B 说一句下一个镜，交替切。
- **群戏 / 会议**：每句台词单独成镜，谁说话镜头给谁（可切无人说话的旁人反应镜）。
- **长对白**（连续 4 句以上）按 **5~8s** 切片，不塞进 10~15s 让一个角色说一长串。
- **单句 ≤24 字**（QC `P1-LONGSENT`）；**每镜台词 ≤18 字**。
- **旁白**：写入 `dialogue`，格式 `旁白：内容`；画外音用 `<voice>角色名</voice>` 标记。
- **speaker_id 全局唯一**（S1 / S2 / …），按出场 / 重要性排序，**一人一号跨集不变**；一人一号一音色，禁止共用 voice_id。

---

## 5. 一致性锚点（七要素 + @锚点）

- **角色 id**：`c01` / `c02` / `c03`…；**场景 id**：`sc001` / `sc002`…；**道具 id**：`p001` / `p002`…。
- **一个角色 = 一套外观锚点**：脸 / 发型 / 服装 / 配饰 / 随身道具，全集只认这一套。
- 分镜引用全部用 id：`character_ids=[c01,c02]`、`scene_id=sc001`、`speaker_id=S1`；不凭想象新建 id。
- 角色库 / 场景库 / 道具库是**一次性资产**，A 级（主角 / 核心 CG 角色）锁定后全片不换。

---

## 6. 分镜硬约束

- **`scene_type` 权威枚举（当前管道只认这三个 + 空值）**：`silent` / `single` / `action`。
  - `silent` = 空镜 / 无对话 / 纯环境；`single` = 单人说话 / 独角戏；`action` = 打斗 / 追逐 / 动作。
  - ⚠️ 方法论（`director-industry-method` / storyboard-breaker）里另有一组细分枚举：`dialogue_2p` / `meeting` /
    `argument` / `long_dialogue`。**这些是"描述层"分类，当前 `validate_db` / `qc_storyboard` 不认**，
    **写进分镜会触发 `P2-SCENE-TYPE`，且不参与视频路由**——实战用**拆镜后的 `single`**（双人对白拆正反打、
    每镜一人说、群戏每句单独成镜）代替，勿直接落库。
- `scene_type=silent` **不允许带台词**。
- **同镜多说话人（>2）建议拆镜**（`action` 除外，见 `P2-MULTI-SPK`）。
- **同一非静态运镜连续复用 ≤6 镜**（`P2-CAMERA-REUSE`），超出应插反打 / 反应镜。
- 分镜字段必填：`image_prompt` / `video_prompt` / `duration` / `scene_id` / `character_ids` /
  `scene_type` / `speaker_id`（无人说话时 `speaker_id` 留空）。

---

## 7. 道具板硬约束（PROP_BOARD_ONLY）

- 宫格图**道具板 / 道具格只展示道具本身**——孤立物品特写、与角色分离，
  **禁止出现人物拿着 / 手持 / 握着道具**（`人物手持道具/手拿道具/拿道具` 进负面词）。
- 道具按归属：只在角色库「随身道具」字段列出的道具才画；**无随身道具的角色不画道具板**
  （表情特写占满右列）。多人可共持同一件「共用标志道具」（如铁皮灯笼 = 帮派标志）。

---

## 8. 声音三层相对电平

- **相对电平：对白 0dB > 音效 −6dB > BGM −14dB**（主次分明，别让 BGM 盖过对白）。
- 整集 **loudnorm 目标 −14 LUFS** 统一（`scripts/assemble_episode.py --loudnorm`），全片响度一致。
- **H3 原生音频为主**：对白 + 环境声靠分镜的 audio Prompt / Speaker / Voice / Emotion 控制。
- BGM / 音效缺的口子用**剪映音乐库 / 音效库**补；对白不稳定 / 需精确配音才上 MiniMax `voice_clone`（不主推自建 TTS）。

---

## 9. 全片复用与分级（一次性资产）

- 角色 / 场景 / 道具 / 包装元素 / 字幕样式 = **一次性资产**，第一集锁定后全集复用，不重复设计。
- **资产分级**（写入 `asset_level` 字段 A / B / C）：
  - **A**：主角 / 核心 CG 角色 —— 锁定 face / voice / 外观，跨集不变。
  - **B**：配角 / 复用道具（帮众、铁皮灯笼等）—— 少量跨集复用。
  - **C**：龙套 / 环境 / 日抛道具 —— 用完即弃，不入长库。
- **跨集复用**：同角色跨集同 id / 同 speaker_id / 同外观 / 同音色；跨集新角色接**亲缘遗传推导**（见 extractor）。

## 11. 图像资产体系（三视图 / 九宫格 / 首尾帧规格）

> 图像资产分四类：**角色三视图 / 场景九宫格 / 分镜首帧 / 分镜尾帧**。全部 16:9（或 9:16），
> 规格固定，是后续 H3 视频工作流的**唯一输入源**，规格不符会断链。

### 11.1 角色三视图（`char_3view_fusion`）—— 每角色一张

- **只做三视图，不做人物全景图**（全景 / 写实大图由场景承担）。
- 布局：**左大版面 = 正面 / 侧面 / 背面 三视全身**；**右列 = 表情板（8 格）**；**右下 = 道具板（仅该角色道具、无人物）**。
- 表情板 8 格（平静镇定 / 温柔浅笑 / 开怀大笑 / 惊讶挑眉 / 皱眉愤怒 / 悲伤垂嘴 / 专注认真 / 忧心不安）：
  同为一人、同脸、同发型、同皮肤；有道具板 → 右上横排一面一格；无道具板 → 右列两列四格占满。
- **道具板只画「有随身道具」的角色**（见 10 道具板硬约束）；无道具角色表情板占满右列，不凭空画道具。
- 统一：16:9、清亮背景、全身从头到脚（含鞋）、**无分割线 / 网格线 / 边框 / 面板轮廓**、
  元素不重叠、不高亮溢出；三视图 + 表情板 + 道具板**同一脸 / 同一服装 / 同一人**。

### 11.2 场景九宫格（`scene_concept` kind `3view`）—— 每场景一张

- **3×3 九格**，同一场景、九个不同机位：大远景 / 全景 / 广角地面 / 中景近景 / 平视中景 / 仰视仰拍 / 俯视航拍 / 局部特写 / 暮色变体。
- **纯环境、完全无人**（九格都无人）；风格 `STYLE_SCENE`；负面 `NEG_SCENE_GRID`。
- **场景专属道具**（`props` 字段）：九格共用同一批道具，**形象 / 轮廓 / 材质 / 颜色 / 尺度 / 摆放跨格一致**；不同场景道具**互不借用**。
- 用**细网格线**分隔九格（不重叠 / 不缺失 / 不溢出）；时间由 `time` 推断灯光基灯（`TIME_LIGHT`），统一叠 `GLOOMY_TONE`（明亮清透）。

### 11.3 首帧 / 尾帧规格（生成顺序 + 一致性铁律）

- **首帧**：text2img，横屏 **1216×832**，`denoise=1.0`，主体 = 分镜 `image_prompt`（`frame_shot(kind="first")`）。
- **尾帧**：img2img，**以本镜首帧图为底图**（`LoadImage` 读 ComfyUI input 目录）+ `denoise≈0.55`；
  **Subject 与首帧【完全一致】**，绝不塞首帧没有的新物体；只把「收尾定格」作为**镜头语言**追加到 `Composition` 尾部——
  保证首尾帧**同一场景 / 同一道具 / 同一人物"不变两版"**。
- **顺序**：先提交 05 首帧 → 生成图复制到 `<ComfyUI>/input/02_分镜/第X集/` → 再提交 06 尾帧。
- **在场角色道具注入**：把该镜在场角色的「随身道具」并进去重、转英文追加到主语尾部（`_attach_props`）。
- **空镜（`character_ids` 空）**：不用角色 LoRA、负面切 `NEG_SCENE_GRID`，显式排人（`absolutely no people, empty environment, no human figure`）。
- **在场人数精确锁定**：有人镜必注入 `strictly exactly N person(s) in this shot, scene shows only these specific character(s), no additional people, no extra crowd, no passing strangers`——**防加错人 / 加群演 / 漏人**。
- **命名带序**：首/尾帧保存前缀 `02_分镜/第X集/第X集_镜{sid}_首帧_写实CG融合` / `..._尾帧_...`，输出名带 `_00001_` 序号，视频工作流按此动态引入。
- 尾帧收尾定格按 `分镜.result` 映射固定英文收尾段（`s01~s17`，兜底 `"the moment resolves as the shot ends"`）。

## 12. 角色外观硬约束（提图必守）

### 12.1 下装必写（硬约束，缺一即穿帮）

- 所有角色**必须穿完整下装**（长裤）+ 鞋，双腿被衣裤完整遮盖，**绝不裸露双腿**。
- 古装长衫 / 长袍 / 裙装（盖腿款式）必写：**内着长裤、足穿布靴/鞋**，从头到脚衣着严整。
- 规则细分：**男 = 长裤 + 鞋；女 = 长裤（或裙装）+ 内衬长裤 + 鞋**。
- 提图层 `LOWER_BODY_PANTS`（正向）强制 `wearing proper full-length trousers ... no bare legs, no exposed thighs or knees ...`；
  负面强排 `没穿裤子/未穿长裤/裸露下体/下身裸露/裸露大腿/光腿/短裙/裆部裸露/赤脚`。
- **提取层必须写完整，不依赖脚本兜底**（`role_look()` 虽会兜底补「内着长裤」，但提取先写对才是根本）。

### 12.2 颜值：默认耐看，"丑"要写进剧本才丑

- **默认角色五官端正、清秀耐看**（`ATTRACTIVE_MALE`/`ATTRACTIVE_FEMALE`，年龄中性，少年/中年均适用）。
- **「凶悍 / 阴鸷 / 狰狞」只是气质 / 表情，不等于丑**——写这些词不会降颜值，会由 `ATTRACTIVE_*` 兜底保持耐看。
- **只有小说明确写"长相丑 / 面貌狰狞"** 才切 `UGLY_CHARACTER_PROMPT` 豁免（丑标记：`丑八怪/丑陋/狰狞/歪嘴/麻子/黄牙/大龅牙/伤疤/独眼`）；
  其他一律读作"普通人长相"，加分项仅限「英武 / 俊朗 / 秀美 / 清秀」。
- **丑 ≠ 凶**：丑触发 `disfigured/ugly/deformed/scarred/rotting teeth`；凶只触发凶悍气质词。二者常被混用，务必按剧本区分。

### 12.3 年龄 / 比例 / 体型

- 按 `age` 分档注入对应头身比（`AGE_PHYSIQUE`：少年 6.5 头身、成年 7~8 头身），防"少年画成成年人、中年画成小年轻"。
- 体型随年龄（少年瘦 / 壮年健硕 / 中年略丰），不写死"童颜巨乳 / 老年少女"这类冲突。

## 13. 世界观与时代锚点（全片统一，跨集不漂移）

- **每剧必须先写死"世界观 / 时代锚点"**（`ERA` / `ROLE_ERA_ANCHOR` / `SCENE_ERA_ANCHOR`），
  是角色外貌、服化道、场景建筑、灯光质感的**统一基准**，跨集 / 跨角色 / 跨场景不漂移。
- **全片（系列级）锚点**：本片《剑噬天下》锁定为**古今双时空融合（修真仙侠 × 现代世家）**——
  古修角色走纯古风，现代角色走现代，同一世界观共存。此为本片**常量**，各集沿用，不做逐集改写。
- **角色 / 场景级锚点按数据逐条声明**（`role_era_anchor` / `scene_era_anchor`）：
  - 每种角色 / 场景**只归一个时代**，禁止"古今元素混进同一角色 / 同一镜"（防现代脸配古装、古装配现代灯）。
  - 同剧多时代（如现代转古代）时，锚点并入 `era_shift` 分段声明，禁止同镜混叠。
- **换剧 / 换世界观必须整体重写本段**（`ERA` / `ERA_BASE` / `ROLE_ERA_ANCHOR` / `SCENE_ERA_ANCHOR`），
  否则沿用上一部剧的时代锚点会造成"时代错位穿帮"（现代脸配古装 / 古装场景配现代灯）。

## 14. 提示词分层（三层解耦）与 H3 六段式

### 14.1 三层解耦（不同层写不同东西，互不混写 / 互不替代）

| 层 | 负责 | 禁区 |
|---|---|---|
| `image_prompt`（首帧/尾帧/参考） | 单帧静帧构图：主体 + 场景 + 光线 + 环境细节 | 不写时间推进 / 动作流动 / 台词 |
| `video_prompt`（时间推进） | 3s 分段的时间演进、动作变化、镜头语言 | 不写台词（台词在 dialogue） |
| audio（对白 / BGM / 音效） | `dialogue` + `bgm_prompt` + `sound_effect` | 不写画面 |

- `description` 适合人读，`video_prompt` 适合模型生成，二者不互相替代。

### 14.2 H3 视频提示词六段式（`build_h3_prompts` 固定结构）

1. **`subject_definition`** —— 锚定主体：`<Picture sc编号>`（场景参考图）+ `<Subject S编号>`（角色参考图，全片复用不漂移）。
2. **`summary`** —— 一句话概括本段画面推进。
3. **`retention_analysis`** —— 留存点分析（为什么留住观众）。
4. **`detailed_description`** —— 逐段时间轴正文：按「3s 推进单元」分段，逐段叠加镜头语言前缀（景别 / 视角 / 运镜 / 时段光线）+ 动作 + 对白段。
5. **`overall_soundscape`** —— 整体声音景观（对白 + 音效 + BGM 情绪，见 15）。
6. **`non_diegetic_music`** —— 非剧情音乐 / BGM 风格。

### 14.3 对白段权威格式（H3 官方内嵌对白）

- 说话：`{说话人英文名} speaks {稳定英文音色描述} (S编号): <d>[中文台词] </d>`
- 旁白：`Narrator speaks {旁白音色} (S11): <d>[中文旁白] </d>`
- **`speaker_id` 来自角色表，不要编造**；音色用**稳定的英文音色描述**，逐镜复用保证同一人同一音色。
- KSampler（视频）参数：**CFG 7，采样 8 步（turbo LoRA）**；参考首帧 + 尾帧约束帧率与时长。

## 15. 音色锚与声音规格

- **speaker_id 全局唯一**（S1~S11，旁白通常 S11），一人一号一音色，跨集不变；**禁止共用 voice_id**。
- **`speaker_id` 是角色顶层字段**，不放进 `voice` 子对象；`voice` 子对象只含 `voice_id`（音色库唯一 ID）/ `voice_desc`（中文描述）/ `role_tag`。`voice_id` 未绑定 = `PENDING_VOICE`（P2 拦截）。
- **音色描述要**一份稳定的英文音色描述（`voice_en`）逐镜复用，保证同一角色跨镜同音色；配音要按性别校正（`align_voice_gender`）。
- **`voice_anchor`**（`LoadAudio → voice_ref`）：跨集锁定音色；留空走 `self_anchor_voice` 自动扩展音色描述。
- **对白 / SFX / BGM 三层电平**：详见 8（对白 0dB > 音效 −6dB > BGM −14dB，整集 −14 LUFS）。
- audio（对白 / bgm / 音效）只在 `dialogue` / `bgm_prompt` / `sound_effect` 里写，与画面层（image/video）解耦。

## 16. 种子管理与可复现

- 每镜（首帧 / 尾帧 / 视频）记录所用 `seed`：**失败重跑时必须保持"相同 seed + 相同输入"** → 得到相同画面。
- 生图种子默认 `42`（`build_new_workflows`），重跑不换 seed；调 seed 只用于"构图失败换一版"，换后记入镜数据。
- 工作流上传 / 重跑时，`seed`、`cfg`、`denoise`、`LoRA 强度`、`尺寸` 必须与本次生成一致，否则结果不可比。
- 跨次生成的一致性，依赖 **seed + 角色 LoRA + 参考图（首帧/三视图）** 三者共同兜底，缺一可能漂移。

## 17. 数据契约字段口径（P0/P1/P2 校验对象）

> 与 `validate_db.py` 保持一致；字段缺失 / 类型错误 / 引用错 id / 越界 = 门禁拦截（详见 18）。

### 17.1 角色（`剧本/03_角色场景/角色.json`，id = `c01`…）

`id` / `name` / `gender`(男/女) / `age` / `role_type`(主角/配角/龙套/旁白) / `role_tag` /
`era`(ancient|modern，时代锚点) / `asset_level`(A/B/C) / `speaker_id`(S1…) / `voice{voice_id, voice_desc, role_tag}` /
`image_prompt` / `随身道具`(中文名数组)。
- **`speaker_id` 在顶层**（非 `voice` 内），一人一号一音色，跨集不变。
- **可选补充字段**：`pose_props` / `appearance` / `性格特点`（当前 `image_prompt` 已内含外貌，`appearance` 仅供兜底）。
- **旁白**：`role_type=旁白`，有 `speaker_id`，但**无实体形象**（不画三视图），只出声音。

### 17.2 场景（`剧本/03_角色场景/场景.json`，id = `sc001`…）

`id` / `name` / `time` / `atmosphere` / `prompt` / `props[{name, image_prompt}]`。

### 17.3 道具（`剧本/03_角色场景/道具.json`，id = `p001`…）

`id` / `name` / `type`(日常/武器/交通/装饰) / `desc` / `image_prompt` / 归属。

### 17.4 分镜（`剧本/02_分镜/第X集_分镜.json`）

- `shot_id` = **两位数字串**（`01` / `02` …，即命名里的 `镜{sid}`；**不是** `S1`，千万别把 `shot_id` 和 `speaker_id` 搞混）。
- `speaker_id` 才是 `S1`…（见 17.1/15），来自角色库。

`shot_id` / `title` / `scene_id` / `scene_type` / `character_ids[]` / `speaker_id` / `shot_type` / `angle` / `movement` /
`time` / `location` / `atmosphere` / `action` / `dialogue` / `description` / `result` / `image_prompt` /
`video_prompt` / `bgm_prompt` / `sound_effect` / `duration`。

### 17.5 通用硬约束

- id **只引用已存在资产**，不凭空新建（`P0/P1-*-UNKNOWN` 拦截）。
- 角色 / 场景 / 道具 / speaker_id 命名**全片唯一**，禁止重复（`P0-*-DUP`）。
- `speaker_id` 必须**属于本镜 `character_ids` 中某角色**，且名字出现在 `dialogue`（`P1-SPK-UNKNOWN`）。

## 18. 质量门禁清单（P0/P1/P2）

> 与 `qc_storyboard.py` / `validate_db.py` 一致；**P0 必须清零，P1 优先修，P2 发警告**。
> - P0（阻断）：单镜超 15s（`P0-DUR15`）、台词按极速也塞不进镜预算（`P0-DIALOG-OVERRUN`）、
>   字段类型错 / id 重复 / 引用未知 id（`P0-*-TYPE` / `*-DUP` / `*-UNKNOWN`）。
> - P1（建议修）：单句 >24 字（`P1-LONGSENT`）、说话人缺失/未知/音色未绑（`P1-SPK-*`）、
>   角色/场景未知（`P1-*-UNKNOWN`）、角色无图（`P1-CHAR-NO-IMG`）、缺 image/video prompt（`P1-NO-*-PROMPT`）、
>   时长档位不足 3 种（`P1-TEMPO-FLAT`）。
> - P2（警告）：同镜 >2 说话人且非 action（`P2-MULTI-SPK`）、同一非静态运镜连续 ≥6 镜（`P2-CAMERA-REUSE`）、
>   `scene_type` 非法（`P2-SCENE-TYPE`，含方法论细分枚举）、silent 带台词（`P2-SILENT-SPK`）、
>   空镜且无戏剧任务（`P2-BLANK-SHOT`）、角色性别/风格/音色缺省（`P2-CHAR-GENDER/NO-STYLE/NO-VOICE`）。

## 附：资产 A/B/C 分级规范（通用规范 + 每集落地模板）

### A. 分级判定标准（通用）

| 级别 | 适用对象 | 判定依据 | 跨集策略 |
|---|---|---|---|
| A | 角色 / 核心场景 / 核心道具 | 主角 / 女主 / 核心 CG 角色；全片主场景；必复用帧；锁定 face/voice/外观 | 跨集复用，**不重做** |
